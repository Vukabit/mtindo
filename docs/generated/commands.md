# xtask commands

Generated by `cargo xtask docs` from xtask's command tree; do not edit.
`cargo xtask help COMMAND` shows the same. CONTRIBUTING.md and
MAINTAINING.md say when each is used.

## `cargo xtask test`

Run the gates and test suites; report each as passed, failed or skipped with a
reason

```text
cargo xtask test [--group GROUP] [--full] [--failed] [--target ID] [--fuzz-time
    SECONDS] [--bless] [--list]
```

- `--group GROUP`: Run only this group; repeatable. Default: gates and tests.
  (one of: gates, tests, heavy, fuzz, bench)
- `--full`: Run every group, including heavy (network), fuzz (nightly) and
  bench.
- `--failed`: Run only the tasks that failed when they last ran
  (.dev/logs/last-test.tsv).
- `--target ID`: Run one task by id, whatever its group (ids are listed below).
- `--fuzz-time SECONDS`: Seconds to fuzz each target. Default: 10.
- `--bless`: Regenerate the regression fixtures' expected outputs, then list
  what changed.
- `--list`: Show which tasks would run, without running them.

## `cargo xtask fuzz run`

```text

```

- `TARGET`: The fuzz target, from fuzz/fuzz_targets/

## `cargo xtask fuzz soak`

Fuzz every target side by side for 24 hours, kept awake and drawn live on a
terminal, then file what they found

```text
cargo xtask fuzz soak [--time SECONDS] [--targets A,B] [--restart]
```

- `--time SECONDS`: Seconds to fuzz each target [default: 86400]
- `--targets A,B`: Only these targets, from fuzz/fuzz_targets/ (default: all)
- `--restart`: Stop a target at each find and start it again (at most 10 times)
  instead of fuzzing on past its finds

## `cargo xtask memst`

Where a Rust program's time and memory go, per function and line: wall and CPU
time, peak memory, sampled CPU time, every allocation, exact timers for the
functions asked about; mto on the corpus's serde by default

```text
cargo xtask memst [PROJECT] [--input PATH] [--bin NAME] [--package NAME]
    [--build release|debug] [--repeat N] [--interval US] [--compare REV]
    [--no-time] [--no-memory] [ARGS...] [--view VIEW,...] [--by
    time|bytes|allocs] [--top N] [--function PATH,...] [--file FILE,...]
    [report]
```

- `PROJECT`: A Cargo workspace whose binary to profile, run with ARGS (default:
  mto, on --input)
- `--input PATH`: Without PROJECT: what mto runs on (default: the corpus's
  serde)
- `--bin NAME`: The binary, when the workspace has several
- `--package NAME`: The package holding the binary
- `--build release|debug`: How the binary is built (default: release)
- `--repeat N`: Plain runs, for wall time, CPU time and peak memory (default 3)
- `--interval US`: How often the sampling run samples, in microseconds of CPU
  time (default 1000)
- `--compare REV`: Profile the tree as of REV (a git worktree under
  target/memst/rev) and the working tree, and compare them
- `--no-time`: No sampling run
- `--no-memory`: No memory run
- `ARGS...`: With PROJECT: the program's arguments, after --
- `--view VIEW,...`: Which views: summary, functions, lines, probes, callers,
  modules, hot, tree, sites, or all
- `--by time|bytes|allocs`: What functions and the tree rank by
- `--top N`: Rows per table (default 20)
- `--function PATH,...`: Functions (a path or its end: roles, file::roles) to
  time exactly with probes, and keep the views to
- `--file FILE,...`: Source files whose every function is probed, and the views
  keep to

## `cargo xtask pairs`

The scrambled-pair suite: corpus files drawn by a fresh seed, items shuffled and
whitespace scrambled (checked token for token), formatted by mto and by the
standard formatter; scored by files and lines matching, and the crates that
compile offline built scrambled, after mto and after the standard formatter;
kept as pairs.* metrics; exits 1 on an mto compile break, an mto panic or a
scrambler bug

```text
cargo xtask pairs [--seed N] [--crates NAME,...] [--files N] [--no-compile]
    [--keep DIR]
```

- `--seed N`: Draw and scramble from this seed, to replay a run (default: a new
  one, printed)
- `--crates NAME,...`: The corpus crates (default: six drawn by the seed, three
  of them crates that compile offline)
- `--files N`: Files drawn per crate; 0 for every file [default: 20]
- `--no-compile`: Score likeness only; build no copies
- `--keep DIR`: Keep the scrambled files and the built copies in DIR (outside
  this repository) instead of a temporary folder that is deleted

## `cargo xtask probe`

```text

```

- `CASE`: A test pair as the diff names it

- `--show KEY`: Show mto's output beside this key's, where they first differ
- `--toolchain NAME`: The nightly toolchain for run@nightly (default: nightly)
- `--scan`: Check every pair; fails on a disagreement not recorded
- `--record`: Record the disagreements found, to triage
