KEYS · vim keys on
  N                          a count, typed before the keys: 5j, 3G, 2gt
  k, up, ctrl+y              up a row; with a count, that many
  j, down, ctrl+e            down a row; with a count, that many
  ctrl+u                     half a pane up; with a count, that many
  ctrl+d                     half a pane down; with a count, that many
  ctrl+b, pageup             a pane up; with a count, that many
  ctrl+f, pagedown           a pane down; with a count, that many
  gg, home                   the first row; with a count, that row
  G, end                     the last row; with a count, that row
  ctrl+w w                   the next pane; with a count, that pane
  ctrl+w W                   the previous pane; with a count, that many
  h, ctrl+w h, ctrl+w left   the pane to the left
  l, ctrl+w l, ctrl+w right  the pane to the right
  ctrl+w k, ctrl+w up        the pane above
  ctrl+w j, ctrl+w down      the pane below
  ctrl+w p                   the pane focused before
  ctrl+w z, ctrl+w o         the focused pane over the whole screen, or back
  ctrl+w q                   number the panes, then go to the one typed
  gt                         the next screen; with a count, that screen
  gT                         the previous screen; with a count, that many
  enter, ctrl+]              open the selected row's page
  esc, ctrl+t                close the page, or clear the search
  ctrl+o, alt+left           back to the place left
  alt+m                      mark where you are, by the letter typed next
  '                          go to the place marked by the letter typed next
  tab, alt+right             forward again
  i, a, enter                give a terminal the keys
  ctrl+\                     take the keys back from a terminal
  esc                        the same, while no full-screen program runs in it
  ctrl+n                     a new tab in a terminal
  ctrl+x                     close a terminal's tab
  ]                          a terminal's next tab; with a count, that tab
  [                          a terminal's previous tab
  R                          rename a terminal's tab
  /                          search the focused pane
  v                          mark the selected row, for an action on all marked; pin a chart's point
  ctrl+a                     mark every row shown, or unmark them all
  alt+y                      copy the focused pane's row or rows: JSON, TSV or Markdown
  >                          sort the focused table by its next column; a chart's window later
  <                          reverse the focused table's sort; a chart's window earlier
  +                          a chart's newest half, and so on
  -                          a chart's window twice as wide
  n                          a log's next search match, or problem line
  N                          a log's previous search match, or problem line
  alt+z                      a log's long lines broken at its width, or not
  F                          every section of a log open, or only those that matter
  :                          the palette: run any command
  !                          the alerts
  ctrl+r                     read every source again
  ctrl+k                     stop the newest action still running
  ctrl+z                     take back the last action that can be, after asking
  ctrl+l                     read the config again
  ?                          this help
  f2                         vim keys on or off
  f3                         the mouse to the hub, or to the terminal to select text
  q, ZZ, ZQ, ctrl+c          quit

PALETTE COMMANDS

  :reload                    read the config again (also :e)
  :w [FILE]                  save this screen as text
  :let NAME VALUE            set a [[variable]]
  :set contrast              high contrast (:set nocontrast the theme's colors)
  :q                         quit (also :q! :qa :wq :x)
  :N                         row N
  :<screen id>               that screen
